# Skill Feedback Inbox

Lessons about how the `sdlc` plugin skills (and any project skills the
workspace adds) should work, captured during daily work and applied by the `sdlc:skill-retro` skill.

## How to add an entry
- Added at the end of a ticket by `sdlc:context-update` (step 5), or at any time
  when the human corrects how a workflow ran.
- One row per lesson. Do not edit skills directly from here — `sdlc:skill-retro`
  applies approved changes.
- Repo facts belong in `ai-context`, and personal working preferences in memory
  or `CLAUDE.md`; only `workflow` and `trigger` lessons go here.

Kind values: `workflow` (a step should run differently), `trigger` (the skill
was or was not chosen when it should have been).

Status values: `open`, `applied` (with the retro date), `rejected` (with the
reason), `deferred` (with what would change the decision).
